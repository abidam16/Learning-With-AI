# Review 002 — Runner

Baca `main.go` tanpa menjalankan program dahulu. Diasumsikan executable ditemukan dan task berhasil dimulai; tidak ada interupsi dari luar.

Untuk pemanggilan `.\lab.exe` tanpa argumen, prediksi urutan pesan terminal dan `$LASTEXITCODE`, disertai alasan alurnya. Tidak perlu mengubah kode.

Sesudah prediksi, instructor atau learner dapat membandingkan dengan:
```powershell
go build -o lab.exe .
.\lab.exe
$LASTEXITCODE
```
